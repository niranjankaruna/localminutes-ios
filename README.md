# LocalMinutes

Local meeting recordings, transcripts, notes, summaries and answers. No account or hosted application service.

- [iPhone application and build instructions](./ios/README.md)
- [Windows application and build instructions](./windows/README.md)
- [Windows and local-network sync implementation plan](./docs/WINDOWS_AND_SYNC_PLAN.md)
